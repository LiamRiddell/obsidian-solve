13-Experiment Lessons Learned

⚠️ Micro-optimizations DON'T work
Every attempt to tweak the infix loop broke V8's inline caches:
✗ Inline consume() → +52%
✗ Remove null checks → +109%
✗ for-loop instead of while → +96%
✗ .length=0 instead of =[] → +269%
✗ Direct index instead of .push() → +6%
✓ Only structural changes survive:
✓ getBindingPower() → bindingPower property
✓ Remove dead parenDelta field
The parser is saturated — V8 owns this code.

💡 Parser+Compiler Improvement Opportunities:
1. Pool BytecodeBuilders — reuse builder instances across expressions (avoids 4 allocs/expr).
2. Skip buildInto() copy for cached expressions — already done via bytecodeCache, but the copy loop still runs on first parse.
3. Use package system for shipped arithmetic — move built-in parselets out of the hot registry lookup into a dedicated fast path.
4. Batch-parse independent expressions — combined token list avoids per-expression Builder/Parser setup.
