# Solve Engine Playground

A web-based playground for debugging the Solve engine's lexer, parser, and bytecode execution.

## Features

- **Token Visualization**: See how the lexer tokenizes expressions with color-coded tokens
- **AST Display**: View the generated bytecode structure
- **Execution Output**: See the result of running expressions
- **Error Reporting**: View syntax and execution errors
- **Dark Theme**: Clean, developer-friendly interface

## Usage

### Running the Development Server

```bash
cd playground
npm run dev
```

Visit http://localhost:5173 in your browser.

### Building for Production

```bash
cd playground
npm run build
```

The built files will be in the `dist/` directory.

### Serving Built Files

```bash
cd playground/dist
python -m http.server 8080
# or
npx http-server -p 8080
```

## Examples

Try these expressions to see the engine in action:

- `10 + 5 * 2` - Basic arithmetic
- `10 + 5 * 2` - Operator precedence
- `sin(3.14)` - Function calls
- `100cm + 1m` - Unit conversion
- `d20` - Dice rolls
- `now + 7 days` - Date operations
- `50% of 200` - Percentage calculations

## Architecture

The playground uses:
- **Vite** for development and building
- **TypeScript** for type safety
- **Engine Integration**: Directly imports from the Solve engine source code
- **No External Dependencies**: Keeps bundle size minimal

## Notes

- This is a development tool, not bundled with the main Obsidian plugin
- Focuses on visualizing internal engine state
- Dark theme optimized for developer productivity
